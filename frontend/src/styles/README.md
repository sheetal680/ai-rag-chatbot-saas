# styles/

Global CSS lives in `src/app/globals.css` (required by Next.js App Router).

Use this folder for:
- Component-level CSS modules (`ComponentName.module.css`) if you ever need CSS that can't be expressed with Tailwind
- Animation keyframe files
- Third-party overrides

In most cases, Tailwind utility classes should be enough — reach for this folder only when you need something Tailwind can't do.
